# Segurança

Este repositório ainda é um esqueleto de API. Ele não oferece autenticação, persistência ou execução de tarefas.

Para reportar uma vulnerabilidade, use a opção de reporte privado de segurança do GitHub para este repositório ou contate os mantenedores pela organização FrancosCorporation. Não abra uma issue pública com detalhes exploráveis.

Dependências usadas pelo servidor devem ficar em dependencies. Ferramentas de build, tipos e desenvolvimento devem ficar em devDependencies. Atualizações de dependências são verificadas pelo workflow de CI.
